# AI Pulse

Rassegna quotidiana automatica con le migliori notizie sull'Intelligenza Artificiale e archivio storico giornaliero.

## Attivazione su GitHub
1. Carica tutti i file (inclusa la cartella `.github`) nel repository pubblico.
2. Vai su **Settings -> Actions -> General** -> *Workflow permissions* -> seleziona **Read and write permissions** e salva.
3. Vai su **Settings -> Pages** -> *Source* -> scegli **GitHub Actions**.
4. Vai su **Actions** -> **Aggiorna Notizie AI e Pubblica** -> clicca **Run workflow**.
